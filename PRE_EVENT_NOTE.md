# Important: use this package responsibly before the hackathon

This package is a technical learning and environment-validation scaffold created before the NASA Space Apps Challenge build window.

Before using any part of it as competition work, check the rules and instructions of the specific local/virtual event selected in your NASA dashboard. Some local event instructions explicitly say participants must not begin building the challenge project before the official start time.

For example, the official Faisalabad 2026 event page says to choose a challenge and start building on November 14 at 9:00 AM Pakistan time, and not to start before then:
https://www.spaceappschallenge.org/2026/local-events/faisalabad/

The official global site says project editing/submission opens November 14 at 9:00 AM local time:
https://www.spaceappschallenge.org/2026/

If your selected event prohibits pre-event development, do not submit this pre-event scaffold as completed hackathon work. Use the preparation period to learn Python, install dependencies, understand the NASA POWER API documentation, assign team roles, and prepare your development environment. Begin the actual challenge implementation at the time permitted by your event.

This is an early prototype scaffold. Its code has been syntax-checked, but live end-to-end API behaviour and statistical outputs still need to be tested on your computer.
